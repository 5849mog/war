# 美术与镜头方向 v0.5

**设计者已选择的美术基调**：希望有《部落冲突》那类明快、立体、轻松的卡通奇幻观感。本项目只取高层的视觉感受：丰富但易读的颜色、夸张的体积与比例、清楚的建筑升级层次、热闹的基地氛围。角色、建筑造型、图标、界面构图、名字和声音都必须从本项目自身的世界观重新设计，不复刻现成素材。

**已确认的镜头**：使用固定 **2.5D 斜视镜头**，底层仍是 28×28 的二维格子与同一战斗规则。镜头不自由旋转；建造、路径、射程和伤害都基于世界坐标结算，斜视只改变画面投影和点选方式。

## 1. 原创视觉关键词

- **饱满轮廓**：建筑底座宽、顶部有明确剪影；单位头部和装备略夸张，远景能认出职责，避免真实比例造成手机上难辨认。
- **有层次的材质**：草地、木、石、金属与复合板各有纹理和明度，不用同一形状只换颜色代表不同等级。
- **轻快的奇幻工艺**：箭塔、机枪台和火炮台同属一座虚构城邦的工匠体系，机械结构风格统一，武器只作为非写实的游戏装置呈现。
- **温暖的聚落感**：道路、篱笆、旗帜与生活小物只作装饰；战斗不展示血腥效果。闲置动画让基地有生命力，不能干扰建造格或射程判断。
- **易读的战斗反馈**：命中、受损、摧毁、升级分别有短而明确的特效；保留信息卡与图标，让玩家在关闭粒子效果后仍能读懂战况。

建议首轮原创配色，仅供概念验证：草地 `#719B55`、道路 `#DDBD82`、木材 `#A96A40`、石墙 `#778A91`、铁墙 `#566B7A`、复合墙 `#499D9B`、友方操作高亮 `#58B9D6`、危险区域 `#D97556`。正式美术需要在手机真实显示尺寸下校色，不能依赖这些十六进制值单独传达信息。

## 2. 建筑和墙体的独立造型

| 实体 | 远景识别符号 | 近景材质与动作 | 升级表现 |
| --- | --- | --- | --- |
| 基地核心 | 多层屋顶围绕一枚原创的导航晶标；3×3 占地最醒目 | 木石工坊逐渐添上金属支撑，晶标轻微旋转 | L1→L3 增加层次、支撑与灯光，不复制任何现有游戏主城造型 |
| 军营 | 低矮的训练棚与明显的旗架 | 训练木桩、工具架的小动画 | 人口提升时棚的容量视觉上扩大，仍维持 2×2 碰撞占地 |
| 箭塔 | 高、细、尖的瞭望轮廓 | 绞盘与弓臂，弹道细且清楚 | 升级增加护板与高处旗帜，不改变 2×2 基座 |
| 机枪台 | 低、宽、圆形旋转底座 | 虚构连发装置与短节奏脉冲火光；不呈现真实枪械细节 | 多一圈装甲和转动部件，近距离压制感更强 |
| 火炮台 | 大口径视觉符号、稳重的方形底座 | 缓慢蓄势、弧形弹道与柔和的范围冲击波 | 炮座更厚，炮管与支架轮廓更强；盲区在选中时可见 |
| 木墙 | 起伏木桩与绳结 | 明亮粗糙、轻巧 | 受损出现非写实缺口 |
| 石墙 | 厚砌块与顶部刻纹 | 冷灰石块、明显厚度 | 换材质后整体轮廓变厚，不只是调色 |
| 铁墙 | 铆接金属护板 | 深蓝灰金属与固定件 | 受损表现为板片变形，不用真实伤害细节 |
| 复合墙 | 陶质装甲与几何边框 | 青绿色点缀、分层板块 | 最高材质一眼能看出，但不能用过强光效淹没单位 |

墙体每段仍独立 HP。美术要支持独段、直线、转角、三向和四向连接；可用邻接掩码选取连接件，连接变化不能改变寻路碰撞。每档墙至少有完好、受损两个状态，建筑则有完好、受损、摧毁后的短暂反馈。战斗结束恢复满血时重新显示完好蓝图。

## 3. 六个兵种的角色轮廓

| 兵种 | 可读轮廓和动作 | 与同类区分 |
| --- | --- | --- |
| 巡卫 | 中等身形，方形护具，稳步前进 | 基础兵，不与高大的铁卫混淆 |
| 迅击者 | 轻装、三角形飘带、快速步频 | 身形窄、动作快，和巡卫拉开速度感 |
| 铁卫 | 矮壮大盾与圆角重甲，慢步幅 | 轮廓最宽，受到攻击时有清楚的格挡反馈 |
| 破垒工 | 背负醒目工具包与大号工匠锤 | 目标为城墙时动作与普通近战不同 |
| 弩手 | 细长轮廓、明确远程器具 | 与箭塔同属工匠语言，但不是塔的缩小版 |
| 榴弹手 | 宽松装备和醒目的投掷背包 | 弹道与范围标识清楚，避免与火炮效果混淆 |

单位移动最好有 8 向或等价的方向表现；如果制作量受限，先用少量方向和镜像验证可读性，再决定完整资产量。受击和退场只用简洁卡通反馈。阵营识别同时使用脚下标记、轮廓边缘和 UI 图标，不只靠服装颜色。

## 4. 镜头、投影和交互建议

固定斜视采用约 2:1 的菱形地砖投影，不旋转镜头。底层建筑仍按整数 `(x,y)` 和 1×1、2×2、3×3 规则占地；屏幕上通过统一的投影与逆投影函数完成绘制和点选。逻辑射程仍按世界坐标计算，屏幕上的圈需投影成椭圆或等价提示，绝不能拿屏幕像素距离决定命中。

遮挡比俯视更关键：按世界深度排序；选中建筑、单位或其背后格时，前景屋顶或大炮台可短暂半透明；放置预览始终画出底部占地菱形。战斗时可显示地面目标标记，即使单位被塔遮住也知道其位置。缩到整图时用简化影子、图标与受击提示；放大后展示材质和细节。手机双指缩放、单指平移与选择保持明确优先级，避免滑动地图误放置建筑。

推荐先以**原创立体模型预渲染成透明背景的方向图**或统一风格手绘精灵制作固定视角画面。规则引擎仍可使用 2D 框架；资源制作方式是工程建议，正式选型要在 M0 样板页验证手机性能和效果。

## 5. UI、动效与音效

- UI 有自己的建筑工坊语言：厚实的按钮外形、简洁清楚的字体、少量材质边框。金币与人口始终可见，建筑信息面板优先显示当前/下级数值；不直接模仿参考游戏按钮位置、图标或排版。
- 建造：合法预览显示底座、占地菱形和射程；非法时有文字原因。确认按钮有明显按下状态；升级有材质替换的短动画。
- 战斗：箭塔是清脆短音、机枪台是轻快连续音、火炮台是低沉但不过响的节奏；声音可单独调节，静音时仍有视觉反馈。
- 驻军掩护：选中内侧守军时，用地面连线和简洁护盾图标显示当前哪个方向受墙或炮台掩护；AI 决定出阵时显示沿真实开口的路径预告，不能用动画把单位直接移过建筑。
- 伤害数字可合并显示，避免 0.2 秒射速的机枪台把屏幕铺满数字。持续效果优先不遮住墙口、目标与部署环。
- 导航、弹窗、战报提供动画减弱选项。美术验收要看最小屏幕尺寸和缩到整图两种状态。

## 6. 资产清单与验收

M0–M2 可用自制几何占位；M5 首版至少交付：地形和道路组、核心与军营各 3 级、三塔各 3 级、四材质墙的连接组、五个 MVP 兵种（含弩手）、驻军掩护与出阵指示、部署/命中/摧毁/升级效果、建筑图标、战斗 UI、设置与战报 UI、对应音效。M6 再补榴弹手。所有资产都要有原始工程文件、导出尺寸、锚点/占地定义、方向/动画帧说明及来源许可记录。

验收同时展示：整张基地缩放视图、放大的建筑细节、三塔同时攻击不同目标、四种墙相邻与受损、五兵种混战、内侧弩手越墙射击和近战守军绕开建筑出阵、手机上的建造与战报。让不知道文字规则的人仅凭轮廓能认出三塔和四墙，并能从动画看出火炮的慢速范围攻击与机枪台的快速单体攻击。若做不到，先改形状或镜头，不以额外发光特效掩盖问题。
