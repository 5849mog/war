# M5 资产来源与许可记录

状态：M5 首发候选版。所有可见图形和声音由仓库自有代码绘制或运行时合成；本阶段未导入第三方图片、模型、音频、字体或游戏素材。

| 内容 | 文件/来源 | 说明 |
| --- | --- | --- |
| 地面、道路、墙、建筑、炮台、驻军、进攻单位、弹道与路径指示 | src/game/renderer.mjs | Canvas 2D 原创矢量程序绘制；固定 2.5D 投影；几何均为本项目原始设计。 |
| 品牌标记 | assets/brand-mark.svg | 本仓库原创 SVG 图形；不代表最终品牌。 |
| 界面音效 | src/audio/effects.mjs | Web Audio 振荡器实时合成，随“界面音效”开关静音；没有外部音频文件。 |
| 字体 | 浏览器系统 UI 字体栈 | 不下载字体文件。 |
| UI 图标 | HTML 文字符号和 CSS | 不引用图标字体或第三方图标集。 |

导出构建保留 SVG 原始文件与 ES 模块源码，方便审查与修改。导出 SVG 使用 viewBox 128×128；人物和建筑以地图坐标/占地作为锚点，在运行时按设备像素比缩放。WAR 与“工匠城邦”均为工作名和占位世界观。
