# WAR：原创基地攻防游戏（工作名）

> 状态：**M0–M4 可运行切片已实现；M5 首发产品化候选实现待环境恢复后验证**。`WAR` 是工作名，世界观采用“奇幻工匠城邦”占位设定，均不是最终品牌。

这是一款单人基地建设与响应式 AI 对战游戏。玩家在手机浏览器横屏建造基地、编排驻军，并主动选择开战进攻 AI 基地。AI 守军在玩家部署后决定留守工事或沿真实通路出阵；AI 不在玩家未开战时自行袭击。游戏借鉴基地攻防这一玩法类型，但世界观、单位、美术、名称、界面和具体规则都独立设计。

## 当前运行切片

M0–M5 候选切片包含手机横屏斜视地图、28×28 格子逆投影点选、建造/升级/出售、驻军站位编辑、九张进攻关卡、五种兵种、三种炮台、固定步长模拟与本机存档。AI 守军仅在玩家首次部署后评估是否留守或沿真实空地出阵，玩家自建基地仍是可编辑并保存的蓝图，战斗使用独立 AI 关卡模板。

### 启动

需要 Python 3 和 Node.js（运行测试）。在仓库根目录执行：

```sh
npm run dev
```

然后在运行服务的设备浏览器打开 `http://localhost:4173`，手机请横屏。准备发布静态构建时先运行 `npm run build`，再将 dist/ 作为静态站点目录提供服务。若服务运行在电脑上、手机和电脑接入同一 Wi-Fi，可在手机地址栏输入电脑的局域网 IP 和 `:4173` 端口。测试命令：

```sh
npm test
```

此切片不需要下载 npm 依赖。规则参数、基地操作、模拟、存档、画面投影和 UI 分属独立模块。刷新页面会从 IndexedDB 恢复保存蓝图；地图可拖动、缩放，点选格子会显示逆投影坐标。

## 不变的设计要求

- 炮台必须有**火炮台、机枪台、箭塔**三种，并在射速、射程、范围伤害和克制关系上明显不同。
- 城墙按**木、石、铁、复合材料**区分耐久、造价和升级。玩家可对单段或选中区域升级；不得重复收费或升级越级。
- 玩家能自行选择兵种组合、布置基地并与具有可解释行为的 AI 对战。
- 建筑和炮台都挡住地面移动与进攻方对其后守军的直接攻击；防线内仅远程驻军能越过己方工事攻击外侧敌兵。
- 所有战斗由同一规则引擎结算；AI 不能使用一套暗中更强的规则。
- 每一轮游戏都能获得明确反馈：金币变化、破坏进度、星级、战报和下一步可升级项。
