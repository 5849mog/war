# WAR：原创基地攻防游戏（工作名）

> 状态：**设计草案 v0.4，尚未开始编码**。本仓库是游戏的产品和工程交接入口。本文档提出可执行的默认方案，标记为「待确认」的选择必须由设计者决定后再固定。

这是一款单人基地建设与 AI 攻防游戏。玩家布置城墙和防御设施，升级基地，配置兵种进攻 AI 基地，也能让 AI 挑战自己的布局。游戏借鉴基地攻防这一玩法类型，但世界观、单位、美术、名称、界面和具体规则都独立设计。

## 不变的设计要求

- 炮台必须有**火炮台、机枪台、箭塔**三种，并在射速、射程、范围伤害和克制关系上明显不同。
- 城墙按**木、石、铁、复合材料**区分耐久、造价和升级。玩家可对单段或选中区域升级；不得重复收费或升级越级。
- 玩家能自行选择兵种组合、布置基地并与具有可解释行为的 AI 对战。
- 所有战斗由同一规则引擎结算；AI 不能使用一套暗中更强的规则。
- 每一轮游戏都能获得明确反馈：金币变化、破坏进度、星级、战报和下一步可升级项。
